## 阶段 2 · 开机自启与进程治理（11-20 ~ 11-21）

用户核心诉求：「只要开机，这台本机就当成服务器正常运行就可以了」。

重要纠偏与决策：

- 用户提出「我把账号密码都给你，写入 SYSTEM 级权限」→ **拒绝接收明文密码**，只需要 UAC 弹窗点「是」，不把凭据写进任何文件/脚本。
- `AtLogOn` 触发器 ≠ 开机无需登录 → 改为 **SYSTEM 账户 + `AtStartup` + Highest** 的 `HomeServer-BootStart` 计划任务。
- 中文 `.bat` 在 GBK cmd 下乱码 → 所有 bat/ps1 统一改**纯 ASCII**；PowerShell 脚本早期加过 UTF-8 BOM。
- `schtasks.exe` / `cscript` / `wscript` / VBS 被安全策略拦截 → 全部改用 PowerShell 工具与 `launch.ps1`。
- `start-all.bat` 导致计划任务卡在 Running → 改 `Start-Process` 启动器。
- 重复进程抢 8080 / 同 Token 多连接 → `launch.ps1` 内置防重复锁：`TcpClient` 探测 `127.0.0.1:8080` + CIM 查 `cloudflared.exe`。
- 对话工具会话里 `Start-Process` 起的进程会被清理 → 用 `start-detached.ps1` 建一次性任务 `HomeServer-StartNow`，让进程**脱离会话独立存活**（任务完成后自动移除）。

产物：`launch.ps1`、`install-boot-startup.ps1`、`一键配置开机自启.bat`、`验证开机任务.bat`、`start-detached.ps1`、`开机自启说明.md`。
