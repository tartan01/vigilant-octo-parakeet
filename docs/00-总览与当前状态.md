## 给接手 Agent 的重要提醒

1. **Token 是敏感信息**：`token.txt` 等同服务器完整控制权，不要外发、不要写进公开文档、不要提交到代码仓库。
2. **当前会话可能有安全沙箱**：历史中执行 `schtasks`、`wsl`、`wmic`、`cscript`、`powershell`（从 Bash 调用）、`Start-Process -Verb RunAs` 都被安全策略拦截过。需要提权或系统级操作时，应准备脚本让用户**本机双击运行**，而不是代执行。
3. **沙箱会话看不到 SYSTEM 任务**：普通权限会话查询 `HomeServer-BootStart` 会返回"找不到"，但任务实际存在（提权进程日志已确认）。判断任务是否真的存在，以 `logs\setup-log.txt` 或用户本机的提权查询结果为准。
4. **所有 bat 脚本必须是纯 ASCII**：中文在 cmd.exe 下按 GBK 解读会乱码导致命令损坏。历史已因此失败一次。
5. **PowerShell 脚本用 UTF-8 BOM**：PowerShell 5.1 读取无 BOM 的 UTF-8 中文会乱码；当前脚本已改为纯 ASCII 规避。
