# 06 — 开机自启配置

## 演进过程（理解为什么是现在这个方案）

| 阶段 | 方案 | 结果 |
|---|---|---|
| 1 | `start-all.bat` + 用户级计划任务 `HomeServer-AutoStart`（AtLogOn） | 任务卡在 Running，`start /min` 让任务一直等子进程 |
| 2 | `launch.vbs` + wscript | cscript/wscript 被安全策略拦截，无法执行 |
| 3 | `launch.ps1`（Start-Process 隐藏启动）+ 用户级 AtLogOn 任务 | 成功，但只在"用户登录时"触发，未登录不启动 |
| 4 | **SYSTEM 账户 + AtStartup 开机任务 `HomeServer-BootStart`** | **当前最终方案**，开机无需登录即启动 |

## 当前有效方案

### launch.ps1（统一启动器）

职责：隐藏启动网站和隧道，带防重复锁，写日志。

关键逻辑：
```powershell
$portBusy = $false
$probe = New-Object System.Net.Sockets.TcpClient
try { $probe.Connect('127.0.0.1', 8080); $portBusy = $probe.Connected } catch {} finally { $probe.Close() }
$tunnelRunning = Get-CimInstance Win32_Process -Filter "Name='cloudflared.exe'" |
    Where-Object { $_.CommandLine -like "*$Root\bin\cloudflared.exe*" }

if (-not $portBusy) { Start-Process pythonw server.py ... }   # 已占用则跳过
if (-not $tunnelRunning) { Start-Process cloudflared tunnel run --token ... }
```

要点：
- 所有路径为绝对路径（SYSTEM 账户需要）
- 防重复检测保证"计划任务触发 + 手动运行"不会起第二套
- 日志记录到 `logs\launch.log`

### install-boot-startup.ps1（任务安装脚本）

```powershell
$Principal = New-ScheduledTaskPrincipal -UserId "SYSTEM" -LogonType ServiceAccount -RunLevel Highest
$Action    = New-ScheduledTaskAction -Execute "powershell.exe" `
             -Argument "-NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File `"$Launcher`""
$Trigger   = New-ScheduledTaskTrigger -AtStartup
Register-ScheduledTask -TaskName "HomeServer-BootStart" -Force ...
```

它会先移除旧的 `HomeServer-AutoStart`，再注册 SYSTEM 开机任务。带 IsAdmin 检查，非管理员直接退出；每步写 `logs\setup-log.txt`。

### 一键配置开机自启.bat（用户提权入口）

纯 ASCII 内容。逻辑：
```bat
net session >nul 2>&1
if %errorLevel% neq 0 (
    powershell -Command "Start-Process -FilePath '%~f0' -Verb RunAs -Wait"
    exit /b
)
powershell -ExecutionPolicy Bypass -File "%~dp0install-boot-startup.ps1"
```
用户双击 → UAC 点"是" → 提权进程执行安装。

## 安装结果（已确认成功）

`logs\setup-log.txt` 记录：
```
IsAdmin: True
SUCCESS: HomeServer-BootStart registered
Verify: state=Ready user=SYSTEM trigger=MSFT_TaskBootTrigger
```

= 任务已注册，SYSTEM 账户，开机触发，状态 Ready。

## 验证方式

- 项目内 `验证开机任务.bat`：提权后显示任务信息并 `Start-ScheduledTask` 模拟开机触发，看 LastTaskResult 是否为 0
- 终极验证：重启电脑，不登录，用手机访问 `https://www.honoweb.com`，能打开即成功

## 关键注意事项

1. **SYSTEM 启动的进程在 Session 0**，任务管理器里可能看不到，属正常，看 `logs\launch.log` 判断
2. **沙箱会话查不到 SYSTEM 任务**：普通权限/沙箱里 `Get-ScheduledTask -TaskName HomeServer-BootStart` 会报"找不到"，但任务真实存在。以 setup-log.txt 或用户本机提权查询为准
3. **bat 必须纯 ASCII**：中文在 cmd.exe 按 GBK 解读会乱码。历史已因 UTF-8 中文 bat 失败一次，改成英文后成功
4. **PowerShell 脚本用 UTF-8 BOM 或纯 ASCII**：PowerShell 5.1 读无 BOM 的 UTF-8 中文会乱码
5. 卸载自启：`Unregister-ScheduledTask -TaskName "HomeServer-BootStart" -Confirm:$false`

## 备选方案（未采用）

`install-service-admin.ps1`：用 NSSM 把网站和隧道注册为真正的 Windows 服务。因 SYSTEM 计划任务已满足需求，未采用。若日后需要更规范的服务管理（如服务依赖、恢复策略图形化），可启用。
