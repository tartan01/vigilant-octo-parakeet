## 安全提醒（给接手 Agent）

1. 不要把 `token.txt` 的内容贴进聊天、日志、commit message 或任何 MD。
2. 需要重启隧道时，用 `launch.ps1` 读本机文件，不要重写 Token 到脚本里。

4. `data/admin-credentials.txt` 只在首次启动时生成；登录后改密码即可，之后可删除该明文文件。
