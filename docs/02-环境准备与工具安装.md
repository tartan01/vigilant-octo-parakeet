## cloudflared 下载（重点坑）

**目标版本**：2026.11.1（GitHub API 查询到的最新版）

**正确文件大小**：`55,483,112` 字节（52.9 MB）

**踩坑过程**：

1. GitHub 直连 `github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe` 不稳定
2. 第一次下载超时被中断，得到 31MB 的**截断文件**
3. 截断文件有合法 MZ/PE 头（AMD64），但执行报"不是有效的应用程序"——**大小校验是唯一可靠判断**
4. 续传尝试（`curl -C -`）也失败（Empty reply from server）
5. **成功方案**：用国内镜像 `gh-proxy.com`：
   ```
   https://gh-proxy.com/https://github.com/cloudflare/cloudflared/releases/download/2026.11.1/cloudflared-windows-amd64.exe
   ```
   18 秒下载完成，53MB，校验通过

**给接手 Agent 的检查方法**：
```
& "<path>\cloudflared.exe" --version
```
应输出 `cloudflared version 2026.11.1`。若报"不是有效应用程序"，先比对文件大小是否为 55,483,112。

## 查询官方文件大小的命令

```bash
curl -s "https://api.github.com/repos/cloudflare/cloudflared/releases/latest" | \
  python -c "import sys,json; d=json.load(sys.stdin); print(d['tag_name']); \
  [print(a['name'], a['size']) for a in d['assets'] if 'windows-amd64' in a['name']]"
```
