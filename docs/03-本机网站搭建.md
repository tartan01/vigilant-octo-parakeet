# 03 — 本机网站搭建

## 设计目标

零依赖的轻量 HTTP 服务：只托管 `site/` 目录的静态文件，附带两个 API 用于验证公网链路和统计访问量。使用 Python 标准库 `http.server`，不装 Flask/FastAPI 等第三方框架，减少依赖和故障点。

## 文件清单

- `home-server/server.py` — 服务端
- `home-server/site/index.html` — 首页
- 监听端口：`8080`，绑定 `0.0.0.0`

## server.py 关键实现

完整源码见项目文件，要点：

```python
from http.server import ThreadingHTTPServer, SimpleHTTPRequestHandler

BASE_DIR = Path(__file__).resolve().parent
SITE_DIR = BASE_DIR / "site"
LOG_DIR  = BASE_DIR / "logs"

PORT = 8080

    def do_GET(self):

        # /api/stats -> 返回 visits.jsonl 行数（访问计数）
        # 其他路径   -> super().do_GET() 走静态文件
```

**关键设计点**：

1. 用 `ThreadingHTTPServer` 而非 `HTTPServer`，支持并发
2. IP 取自 `X-Forwarded-For` 首段（Cloudflare 会写这个头），否则回退到 `client_address`
3. 访问记录写成 JSONL，字段含 ip / time / path / ua，便于后续统计
4. `log_message` 置空，避免控制台刷屏（后台无窗口运行看不到）

## index.html

一个自包含的单页，浅色主题，显示：服务运行中徽章、本机实时时间、访问者 IP、当前 URL、状态。IP 通过 `fetch('/api/info')` 异步填充。无外部资源依赖，加载快。

## 本地验证命令

```bash
cd "<home-server>"
python server.py
# 另开终端：
curl -s -o /dev/null -w "HTTP %{http_code}\n" http://127.0.0.1:8080/
curl -s http://127.0.0.1:8080/api/info
curl -s http://127.0.0.1:8080/api/stats
```

预期：首页 HTTP 200；`/api/info` 返回 `{"ip": "...", "time": "..."}`；`/api/stats` 返回 `{"visits": N}`。

## 端口冲突须知

历史上出现过两个 `pythonw.exe` 同时抢 8080（一个来自计划任务、一个来自手动运行），导致连接抖动。**`launch.ps1` 已内置防重复锁**：启动前用 TcpClient 探测 8080，端口占用就跳过网站启动。

注意：`Get-NetTCPConnection -LocalPort 8080` 在计划任务的脚本上下文里曾返回空（不可靠），最终采用 `System.Net.Sockets.TcpClient.Connect('127.0.0.1',8080)` 探测，这是最稳的方式。
