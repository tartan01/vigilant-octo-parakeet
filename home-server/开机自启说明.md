# 开机自启说明

## 当前状态（2026-11-20 22:56 验证）

网站与 Cloudflare Tunnel 已能从公网访问：`https://www.honoweb.com`

**当前自启方式**：计划任务 `HomeServer-AutoStart`，触发条件是「用户登录时」（AtLogOn，绑定 romanovsky 用户）。

**验证结果**：停掉全部服务进程后触发该任务，结果码 0，网站与隧道两个进程自动拉起，公网 HTTP 200 恢复。也就是说——只要你登录进 Windows 桌面，服务就会自动在后台跑起来。

## 重要边界

「登录时自启」≠「开机自启」。如果开机后停在登录界面不输密码，服务不会启动，公网就访问不了。

如果你要的是**只要开机、不登录也能对外服务**，请执行下面的一次性配置。

## 升级为开机自启（无需登录，推荐）

**操作**：双击运行 `一键配置开机自启.bat` → 弹 UAC 时点「是」→ 看到「配置完成」即可。

它会做三件事：
1. 自动请求管理员权限
2. 移除旧的登录时任务 `HomeServer-AutoStart`
3. 创建 SYSTEM 权限的开机任务 `HomeServer-BootStart`（AtStartup 触发，最高权限）

完成后验证：
```powershell
Get-ScheduledTask -TaskName "HomeServer-BootStart" | Select-Object TaskName,State
```
状态显示 Ready 即成功。之后每次开机（即使不登录），网站和隧道都会自动运行。

## 防重复机制

`launch.ps1` 内置防重复锁：启动前先探测 8080 端口和 cloudflared 进程，已在运行就跳过。所以：
- 计划任务触发 + 你手动运行 launch.ps1 → 不会起第二套
- 每次启动记录到 `logs/launch.log`

## 注意

- SYSTEM 启动的进程运行在 Session 0，任务管理器里可能看不到，属正常现象；看 `logs/launch.log` 确认即可。
- `token.txt` 等同服务器密钥，勿外发。
- 若以后要彻底卸载自启：
  `Unregister-ScheduledTask -TaskName "HomeServer-BootStart" -Confirm:$false`
