安全说明

管理员密码以 PBKDF2-HMAC-SHA256（20 万次迭代、随机盐）存储，代码与仓库中不含任何明文凭据。初始凭据仅存在于本机 data/admin-credentials.txt，该目录已被 gitignore。

后台会话为服务端内存会话（8 小时有效），生产环境可替换为 Redis 或 Spring Session。
